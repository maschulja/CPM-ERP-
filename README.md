# CPM-ERP-
Создание сайта для кондитерской.

Создание сайта для кондитерской, где клиент будет оформлять заказы. У клиента будет личный кабинет, история заказов. На сайте будет общая информация о кондитерской, меню с ценами, фотографии работ, корзина, чат с менеджером и клиентом. Сайт будет связан с БД. Заказ, после оформления, отправляется на производство. У производства будет своя система работы с заказами.
